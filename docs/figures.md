# Figures of the paper

[Back to the documentation index](README.md)

All 30 figures of the manuscript are in [`figures/`](../figures), as PDF (vector) and PNG (300 dpi). The table gives the
figure number in the manuscript, the file name and the script that draws it; a script in brackets produces the input
table that the figure needs. Re-drawn figures are written to `analysis/figures/`, so the published versions are not
overwritten.
